# StudyMate — Student Task Manager

StudyMate is a Flutter application designed to help students organise their academic workload, keep track of assignments, and manage their study tasks in one place.

## Features

- **Student dashboard:** A welcoming dashboard with an overview of study tasks.
- **Task management:** Add and organise study tasks.
- **Task status:** Track pending and completed assignments.
- **Task filters:** Filter tasks by status, including all, pending, completed, and overdue.
- **Assignment tracking:** Keep upcoming academic work organised.
- **Cross-platform development:** Built with Flutter and Dart.

## Getting Started

### Prerequisites

Install the following tools before running the project:

- Flutter SDK
- Dart SDK (included with Flutter)
- Android Studio or another supported development environment

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/KhensaneM/StudyMate.git
   ```

2. Navigate to the project directory:

   ```bash
   cd StudyMate
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application on a supported device:

   ```bash
   flutter run
   ```

To run the Linux desktop version, use:

```bash
flutter run -d linux
```

## Testing

Run static analysis:

```bash
flutter analyze
```

Run automated tests:

```bash
flutter test
```
